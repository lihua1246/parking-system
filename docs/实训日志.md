# 实训日志

每天收工前填写，当天的事当天记。每人两三句即可，写具体的事，不写"继续开发"这类空话。
这份日志会直接进入实训报告的"二、实训日志"。

填写要求：

- **完成**：写到需求编号或任务卡，例如"完成 REQ-003 住户查询，合并请求 #7 已合入"。
- **问题与解决**：遇到了什么、怎么发现的、怎么解决的。这是实训总结的素材。
- **学到**：今天弄懂的一个概念或做法。
