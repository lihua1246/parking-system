## ADR-001：界面采用 PySide6 桌面程序

**状态**：暂定，等老师确认界面要求（需求卡 Q1）

**背景**：任务书没有规定界面形式。需要在命令行、Tkinter、PySide6、网页之间选择。

**候选方案**

| 方案 | 优点 | 缺点 |
|---|---|---|
| 命令行 | 最省事 | 表格、图表展示困难，答辩演示效果差 |
| Tkinter | 标准库自带，不用安装 | 表格和布局能力弱，界面简陋 |
| PySide6 | 表格、对话框、图表嵌入都成熟，外观接近正式软件 | 需要安装，概念比 Tkinter 多 |
| 网页（Flask） | 界面自由度高 | 要额外学 HTML 和前后端交互，两周内风险大 |

**决定**：PySide6。

**原因**：系统以表格和表单为主，PySide6 的表格控件直接可用；全员使用自己的电脑，安装不是问题；有 AI 助手辅助，学习成本可接受。

**代价**：新增一个较大的依赖；组员需要理解信号与槽的基本用法。

**重新评估的条件**：老师明确要求网页或命令行；或第 3 天 MVP 时界面进度明显拖后。由于界面与业务规则分层，更换界面只影响 `app/ui/`。

## ADR-002：数据存储采用 SQLite

**状态**：暂定，等老师确认数据库要求（需求卡 Q2）

**背景**：任务书要求掌握数据库设计，但未指定数据库。

**候选方案**

| 方案 | 优点 | 缺点 |
|---|---|---|
| 文本或 JSON 文件 | 最简单 | 查询、唯一约束都要自己写，体现不出数据库设计 |
| SQLite | 标准库自带，数据库就是一个文件，换电脑演示不用配置 | 不适合多人同时写入 |
| MySQL | 更接近企业环境 | 每人都要安装和配置服务，答辩现场连接失败的风险高 |

**决定**：SQLite。

**原因**：系统单机使用，没有并发需求；五个人的环境零配置即可一致；测试可以用内存库，速度快且互不影响。

**代价**：没有练到数据库服务的安装与账号管理。

**重新评估的条件**：老师要求使用 MySQL。届时只需修改 `app/repository/db.py` 的连接方式和少量 SQL 方言差异。

## ADR-003：业务规则与界面、数据库分离

**状态**：已采纳

**背景**：计费和统计是最容易出错的部分。如果公式写在按钮的点击事件里，每次验证都要启动程序、手工录入、肉眼核对，五个人各自用 AI 助手开发时尤其难以发现错误。

**决定**：计费、统计、预警、校验全部放在 `app/services/`，写成不依赖界面和数据库的类或函数；当前时间由调用方传入。

**原因**：这样可以用固定的输入直接断言输出，例如"停 31 分钟应收 3 元"；负责人和 AI 助手都有明确的对错标准；界面和数据库更换时规则不用重写。

**代价**：文件数量变多；一个功能要分别在三层各写一部分，初学时会觉得绕。

**重新评估的条件**：无。这是本项目的基本结构。

## ADR-004：出入记录只增不删，并保存入场时的车辆信息副本

**状态**：已采纳

**背景**：出入记录是收费和统计的依据。如果允许删除或随意修改，统计结果无法解释；如果记录只保存车辆编号，车辆资料后来被修改或删除，历史记录就会失真。

**候选方案**

1. 普通增删改查，记录通过外键关联车辆表。
2. 记录只允许新增和补全出场信息，并在记录中保存入场时的车牌和车辆类型。
3. 完整的事件溯源：所有数据都由事件回放得到。

**决定**：方案 2，且只用于出入记录这一张表。住户、车辆、车位仍是普通增删改查。

**原因**：出入记录是"发生过的事实"，需要长期可信；其他资料是"当前状态"，普通增删改查足够。方案 3 对两周的项目来说成本过高，收益不明显。

**代价**：车牌和类型在两张表中各存一份；录错的记录不能删除，只能通过备注说明。

**重新评估的条件**：如果确实需要更正错误记录，增加"更正记录"功能（新增一条说明，保留原记录），而不是开放删除。

## ADR-005：金额用整数，按 24 小时周期封顶

**状态**：已采纳

**背景**：停车费需要精确计算并与手算结果比对。"每日封顶"有两种理解：按自然日（0 点到 24 点），或按入场后每满 24 小时。

**决定**：金额用整数（单位：元）。封顶按入场后每 24 小时为一个周期计算。

**原因**：浮点数做金额运算会出现 0.1 + 0.2 ≠ 0.3 这类误差，单价设为整数元即可避免；按 24 小时周期计算比按自然日简单，停车时长相同则费用相同，容易测试，也容易向用户解释。

**代价**：不支持"每小时 2.5 元"这样的单价；与部分真实停车场按自然日封顶的做法不同。

**重新评估的条件**：需要支持小数单价时，改用"分"为单位的整数，而不是改用浮点数。
