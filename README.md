# 小区车辆管理系统

郑州轻工业大学《面向对象程序设计实训》小组项目（选题 X8）。

用 Python 实现的桌面管理系统：管理小区住户、车辆、车位，登记车辆出入，按规则自动计算停车费，并提供统计报表。

## 运行

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python main.py                  # 启动程序
pytest                          # 运行全部测试
```

首次启动会在 `data/` 下自动创建数据库，默认管理员账号 `admin` / `admin123`（首次登录后请修改）。

## 技术选型

Python 3.10+、SQLite（标准库 sqlite3）、PySide6（界面）、matplotlib（图表）、openpyxl（导出）、pytest（测试）。
选型理由见 [docs/04-决策记录.md](docs/04-决策记录.md)。

## 目录

```
main.py              程序入口
app/models/          数据类
app/services/        业务规则（不依赖界面和数据库）
app/repository/      数据库读写
app/ui/              界面
tests/               测试
docs/                项目文档
```
